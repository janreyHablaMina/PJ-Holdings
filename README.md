# PJ-Holdings

An independent venture and creative practice dedicated to the architectural execution of digital flagships, sovereign brands, and venture capital enterprises.

## Project Structure

- `web-pj/` - Next.js (App Router) + TypeScript + Tailwind CSS + Three.js 3D WebGL agency portfolio.

## Getting Started

To run the web application locally:

```bash
cd web-pj
npm install
npm run dev
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.
